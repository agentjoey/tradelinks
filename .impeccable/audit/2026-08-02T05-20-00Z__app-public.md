## Detailed Findings by Severity

- **[P2] Cookie-consent banner overlays first-visit content**
  - Location: `app/components/Analytics.tsx:60` (outside Task 2 contract scope)
  - Category: Accessibility / Implementation Integrity
  - Impact: on first visit only, the fixed bar can sit over the Monitored card's limit note — the surface's most important sentence. One-click dismiss clears it permanently.
  - Recommendation: owner decision — take the banner out of the overlay layer (in-flow bottom bar) in a later task. The regression this task introduced (phantom 4rem MobileTabBar clearance on mobile) is already fixed in `app/globals.css`.
  - Suggested command: `$impeccable harden`

- **[P3] House micro-type density (9px eyebrow, 10px evidence markers)**
  - Location: `app/(public)/PublicNav.tsx:37`, `app/(public)/page.tsx` evidence rows, `app/(public)/StatePanel.tsx`
  - Category: Accessibility
  - Impact: below comfortable legibility for low-vision users; not a WCAG violation (no minimum size), identical to the approved mockup's CSS and the BL-045 house standard.
  - Recommendation: keep (approved design); revisit globally if the house density standard changes.

- **[P3] Hard-coded scrim `bg-black/70` in sheet.tsx**
  - Location: `components/ui/sheet.tsx` (SheetOverlay)
  - Category: Theming
  - Impact: none visible — modal scrims are conventionally black in both themes; token system has no scrim token.
  - Recommendation: accept, or add a `--c-scrim` token when the shell first uses Sheet.

- **[P3] Global `prefers-reduced-motion` 0.01ms kill**
  - Location: `app/globals.css` base layer
  - Category: Accessibility (motion)
  - Impact: destroys transition feedback in principle; in practice the public shell's transitions are color-only (hover/focus), so no state information is lost. Pre-existing house pattern; every BL-045 choreography animation also has an explicit `animation: none` fallback.
  - Recommendation: accept for Phase 1; consider a fade-preserving alternative if motion ever carries state.

- **[P3] Touch targets below the 44px AAA guideline**
  - Location: `app/(public)/PublicNav.tsx` links (36px mobile), ThemeToggle (34px)
  - Category: Responsive
  - Impact: meets WCAG 2.2 AA 2.5.8 (24px minimum); does not meet the AAA 44px guideline.
  - Recommendation: accept at AA; bump ThemeToggle to 44px if AAA is ever targeted.

- **[P3] "EN" indicator styled like a control**
  - Location: `app/(public)/PublicNav.tsx`
  - Category: Accessibility / consistency
  - Impact: inert text in the same mono/uppercase style as the footer links; could be mistaken for a language toggle. English-only Phase 1 makes it informational.
  - Recommendation: accept (matches approved mockup); restyle when locales return.
